## Rules

Route pages belong inside:

src/pages

Reusable UI belongs inside:

src/components

Generic UI belongs inside:

src/components/common

API communication belongs inside:

src/services

Custom hooks belong inside:

src/hooks

Context providers belong inside:

src/context

Utilities belong inside:

src/utils

Themes belong inside:

src/themes

Global styles belong inside:

src/style
